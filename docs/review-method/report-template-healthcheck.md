# Healthcheck anomaly review — report template (free run)

Fill only what was actually run; missing evidence is written as UNPROVABLE.
Generic advice or repeating free output is not a deliverable.

- Run, date, tool version:【】
- The requester's decision and the agreed question:【】
- Input source, window, sanitization:【】
- What the free tools already answered:【】
- The additionally agreed checks actually performed this run:【commands, evidence references, results】
- Finding and alternative explanations:【separate observation from inference; a retry chain alone does not prove double billing】
- Impact on the decision:【keep investigating / no change needed / more evidence — with the basis】
- What could not be judged, and the evidence missing:【】
- Next actions and re-check conditions:【applicable commands, expected observations; no root-cause guessing, no savings promises】
- Data-handling facts:【what was actually used, retained, deleted — never default-claim isolation or deletion】

A no-finding must still state which agreed checks were run. One clarification
round is included; corrections to this delivery are part of it. New tasks get
a freshly agreed scope.

If the check was useful, a star on the repo helps others find it — never
required, never a condition.
